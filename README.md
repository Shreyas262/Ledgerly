# Ledgerly

Ledgerly is a **front-end expense management application** designed to help organizations manage, review, approve, and analyze business expenses through a centralized interface.

## Features

- Authentication and protected routes
- Role-based access control (RBAC)
- Expense creation and management
- Expense approval workflow
- Receipt upload UI
- Budget management
- Spending analytics and dashboards
- Expense policies
- User and role management
- User profile and settings
- Audit logs and security activity

## Tech Stack

- React
- TypeScript
- Material UI
- Redux Toolkit
- RTK Query
- MSW
- Vite

## Project Status

The core front-end features are implemented. MSW is currently used to simulate the backend and API interactions.

## Future Scope

- Integrate a production backend and PostgreSQL database
- Implement real authentication and session management
- Persist expense receipts using object storage
- Enforce authorization and business rules on the backend
- Add real-time notifications
- Expand reporting and analytics
- Production deployment and monitoring

## Note

Ledgerly is currently a **front-end portfolio project**. The mock API provided by MSW simulates backend functionality for development and demonstration purposes.
